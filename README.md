# CS Quiz Arena - Real-time Multiplayer Quiz Game

A real-time multiplayer quiz game focused on Computer Science topics, built with Node.js, Express, and Socket.io.

## Features

- 🎮 Real-time multiplayer gameplay with WebSockets
- 👑 Host controls (start game, manage questions)
- 📚 Full CRUD operations for quiz questions (Add/Remove)
- 💻 Computer Science themed question bank
- 📱 Fully responsive design (works on laptop and phone)
- 🔐 Private game rooms with room codes
- ⚡ Instant feedback and score updates
- 🏆 Leaderboard at game end

## Tech Stack

- **Backend:** Node.js + Express
- **Real-time:** Socket.io
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Storage:** JSON file-based persistence
